## Implemented architecture paths

- PE32 images select Capstone's 32-bit decoder, 32-bit address wrapping,
  ESP/EBP stack semantics, and four-byte pointers.
- PE32 guest contexts support four-byte memory slots and a register-backed
  native x86 projection. A context that has not been proved stays explicitly
  labelled `native_i386` / `NATIVE_STATE_ONLY`; LLVM refuses to emit it as an
  executable Guest listing.
- Win32 stdcall imports, decorated exports, caller-side cleanup, and bounded
  direct callee-return proofs establish stack cleanup only when the evidence
  identifies it. Unknown or conflicting contracts stop recovery.
- PE32 call-next+1 return-address thunks execute their real stack rewrite,
  including the arithmetic flags produced by `add [esp], imm`.
- Shared x86 semantics cover string operations, `pushad`/`popad`,
  `loop`/`jecxz`, `cmpxchg`, `bt`, segment bases, and four-byte push/pop/ret.
- AMD64 semantic-neutral `bnd`, `repz`/`repe`/`rep`, `xacquire`,
  `xrelease`, and `notrack` prefixes no longer replace the underlying branch,
  return, indirect transfer, or atomic `cmpxchg` operation.
- LLVM emits either `i386-pc-windows-msvc` or
  `x86_64-pc-windows-msvc`. The payload header records the native width;
  PE32 payloads use HIGHLOW relocations, 32-bit RVA writes, x86 runtime
  helpers, and validate the host machine type before injection.
- The i386 toolchain selects an `i686` CPU. Its MSVC `__chkstk` /
  `__alloca_probe` helper probes from the current native ESP, writes guard
  pages, moves ESP to the completed allocation, and carries the return
  address to the new stack frame.

## Known limits

PE32 support is implemented across decoding, context projection, Win32 call
boundaries, shared instruction semantics, listing metadata, LLVM target
selection, payload linking, relocation, injection, and runtime execution.
Individual packed or runtime-generated code can still stop with an explicit
unresolved result. Such a result is preserved as incomplete evidence rather
than converted into a plausible executable Guest listing.
